# Техническое задание: 1С:ГРМ AutoBackup

## 1. Общее описание

Программа для автоматического скачивания последних бэкапов работающих конфигураций 1С:ГРМ по расписанию с сохранением в иерархическую структуру папок и ограничением количества хранимых бэкапов.

**Язык:** Go  
**Стиль UI:** Fluent (через fyne-fluent-theme или custom)  
**Платформа:** Windows x64  
**Тип:** Десктопное приложение с системным трей

---

## 2. Функциональные требования

> **Полное описание API 1С:ГРМ** см. в файле [API.md](API.md)

### 2.1. Автоматическое скачивание бэкапов
- Подключение к Partner API 1С:ГРМ v2 (`https://service-api.1capp.com/partner-api/v2`)
- Аутентификация через Bearer JWT токен
- Получение списка работающих приложений (`status == "running"`)
- Скачивание **последнего бэкапа** для каждого приложения
- Сохранение по структуре:
  ```
  backups/
  ├── Клиент1/
  │   ├── Приложение1/
  │   │   └── backup_2026-10-16.zip
  │   └── Приложение2/
  │       └── backup_2026-10-16.zip
  └── Клиент2/
      └── Приложение3/
          └── backup_2026-10-16.zip
  ```

### 2.2. Управление количеством бэкапов
- Настраиваемый лимит хранимых бэкапов (по умолчанию: 7 последних)
- Автоматическое удаление старых бэкапов при превышении лимита
- Проверка свободного места на диске перед скачиванием

### 2.3. Планировщик
- Настраиваемое расписание (каждые N часов / ежедневно в заданное время)
- Возможность ручного запуска по кнопке
- Логирование каждого запуска и результата

### 2.4. Системный трей
- Иконка в трее с индикаторами состояния:
  - 🟢 Зелёная — работает нормально
  - 🟡 Жёлтая — скачивание в процессе
  - 🔴 Красная — ошибка
  - ⚪ Серая — остановлена

## 3. Интерфейс (контекстное меню трее)

```
┌─────────────────────────────────┐
│  🔄 Обновить сейчас              │
├─────────────────────────────────┤
│  ⚙️ Настройки                   │
│  📊 Монитор действий             │
│  📝 Лог                         │
├─────────────────────────────────┤
│  ▶️ Старт / ⏹️ Стоп              │
│  ❌ Выход                        │
└─────────────────────────────────┘
```

### 3.1. Окно настроек
- API URL и JWT токен
- Папка сохранения бэкапов
- Лимит количества бэкапов на приложение
- Расписание (интервал в часах / точное время)
- Список исключений (какие приложения не скачивать)
- Максимальное использование диска (MB)

### 3.2. Монитор действий
- Текущая операция (какое приложение скачивается)
- Прогресс-бар скачивания
- Статус последнего запуска
- Время до следующего запуска
- Список последних операций

### 3.3. Лог
- Временные метки
- Уровни: INFO, WARNING, ERROR, DEBUG
- Поиск и фильтрация по тексту/уровню
- Автоскролл
- Очистка лога

## 8. Flow работы программы

```
1. Запуск → Загрузка config.json
2. Проверка JWT токена → Авторизация в API
3. Получение списка running приложений
4. Для каждого приложения:
   ├── Получить список бэкапов
   ├── Выбрать последний (status == "ready")
   ├── Скачать по ссылке (link)
   ├── Сохранить в backups/{Client}/{App}/backup_date.zip
   ├── Проверить лимит → Удалить старые если > limit
5. Ждать до следующего запуска (по расписанию)
6. Повторять цикл
```

## 12. Известные ограничения

- API 1С:ГРМ возвращает ссылки на бэкапы с ограниченным временем жизни
- Бэкапы могут быть большими (до нескольких ГБ)
- Требуется стабильное интернет-соединение
- JWT токен имеет срок действия (нужна авторизация)
